# SkyMP YACA TS

> На 29.10.2026: новый [Plugin Runtime Loader](docs/PLUGIN_RUNTIME.md) доставляет client-код/UI подписанными пакетами игрового сервера. Общим runtime/Launcher один раз нужен bootstrap; совместимые обновления затем остаются в плагине. Старые описания ниже действуют лишь при согласованности с новым контрактом. Изменение только в исходниках; новые builds/ZIP/игровая приёмка предстоят.

YACA/TeamSpeak-плагин для SkyMP-fork с браузером SkyrimPlatform. Оператор добавляет каталог, настраивает TeamSpeak, включает плагин. Server-код/`gamemode.js` менять не нужно. Предупреждение соединения и транспорт в `server.js`; постоянный индикатор дальности использует **SkyMP UI Core**.

Индикатор использует стиль рунической печати/кольца Metabolism, перемещается/масштабируется через `/UiEdit`. YACA даёт лишь данные: дальность, микрофон активен/заглушён/отключён, звук/речь. В печати стоит дальность, например «8 / 40 m»; кольцо вокруг показывает её относительно наибольшей дальности из `voiceRanges.ranges` (полное кольцо = наибольшее значение, половина кольца = 50 %). TeamSpeak/YACA mute/unmute автоматически окрашивают руну и кольцо, даже при блокировке дальности: золотой — активен, зелёный — речь, оранжевый — микрофон/звук заглушены или отключены, а также без TeamSpeak. При заглушённом/отключённом микрофоне или звуке речь не показывается. Под печатью больше нет status-текста; при речи элемент остаётся на месте. F8 сохраняет подсказки клавиш; предупреждение принадлежит YACA. Изменение подготовлено исходниками, позже нужны сборки YACA server-plugin/UI-Core runtime.

<a id="aktueller-umfang"></a>
## Текущий объём

- Соединение/переподключение по локальному YACA-WebSocket.
- INIT/JOIN, player-client-ID, канал, речь, микрофон, звук.
- До восьми дальностей, прямое переключение **V**, дополнительно Numpad +/−.
- Серверная блокировка дальности, приватная индикация UI Core.
- Пространственный список игроков с метрами/разделением интерьеров.
- Полупрозрачное полноэкранное предупреждение с парящей сменной картинкой до подключения TeamSpeak/YACA к нужному серверу/игровому каналу.
- Необязательные настройки **F8**, Escape закрывает.
- Необязательный `onVoiceActivity` для своей VAD-интеграции.

**Проверка:** локальная сборка, автоматические bridge/protocol-тесты, Chromium с имитацией YACA, существующий native server-addon. Настоящее TeamSpeak-аудио и игра Skyrim/CEF ещё требуют проверки. Автоматической анимации губ, радио, телефона, мегафона нет.

<a id="schnellstart-für-die-vorschau"></a>
## Быстрый просмотр

Node.js 22+:

```powershell
npm ci
npm run preview
```

Открыть `http://127.0.0.1:4173`. Только примерные данные. Собранный пакет запускается `npm start`, npm-зависимости не нужны.

<a id="lokal-in-skymp-testen"></a>
## Локальный тест SkyMP

**Plugin-ZIP** прямо содержит `Plugins/skymp-yaca-ts/`. Установка:

1. Поместить каталог в `Plugins/` игрового сервера.
2. В `config.json` указать реальные UID TeamSpeak и ID каналов.
3. Включить существующим plugin/admin-workflow, перезапустить игровой сервер. Новые плагины в форке сначала отключены.
4. Для индикации включить `skymp-ui-core`, поставить его client/CEF-интеграцию. Без UI Core предупреждение и клавиши работают; постоянный индикатор ждёт UI Core с одним сообщением журнала.

Стандартная картинка: **`assets/voice-required.svg`**. Заменить либо в `config.json` через `ui.connectionOverlay.imagePath` выбрать PNG/JPEG/WebP/SVG из `assets/`; перезапустить сервер. Пересборка не нужна. Текст, alt, непрозрачность настраиваются там же, детали в установке.

Npm-зависимости на сервер не устанавливаются. Прежний gamemode остаётся, его перезагрузки учитываются.

Установка: [docs/PLUGIN-INSTALL.md](docs/PLUGIN-INSTALL.md). Тесты разработки/preview: [docs/LOCAL-TEST.md](docs/LOCAL-TEST.md). Реальный fork/открытые lipsync-проблемы: [docs/COMPATIBILITY.md](docs/COMPATIBILITY.md).

```powershell
npm test
./tools/package-local.ps1
```

Локальная упаковка создаёт plugin-ZIP/исходный пакет в `artifacts/`, без commit/push/upload. Build также создаёт установочный каталог с `assets/` в `dist/plugin/`. Исторические Papyrus-файлы не устанавливаются.
